# AgroSustent-vel-agrinho2026

O objetivo do site é promover o equilíbrio entre a alta produtividade no campo e a preservação ambiental. Ele destaca o uso de tecnologias verdes (como drones e bioinsumos), gestão inteligente da água e o uso de energias limpas (solar e biomassa). Além disso, possui um botão interativo para exibir mensagens motivacionais e um formulário funcional de contato para capturar novos interessados no movimento.

Assistência (Texto e Ideias de Código): ChatGPT e Gemini.
